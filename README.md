## Deskripsi Proyek
Sistem Informasi Pemesanan Produk Handmade pada Biruberbinar berbasis web yang memudahkan pelanggan melihat katalog produk, galeri pembeli, detail produk, serta melakukan pemesanan dengan pilihan warna, jumlah, dan permintaan khusus. Sistem dilengkapi fitur registrasi dan login pelanggan, notifikasi pemesanan berhasil, serta integrasi WhatsApp untuk komunikasi dan konfirmasi pesanan. Admin dapat mengelola data pelanggan, produk, harga, stok, katalog warna, estimasi waktu pengerjaan, dan memantau status pesanan mulai dari proses pemesanan hingga selesai dan siap dikirim
